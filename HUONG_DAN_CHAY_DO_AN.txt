CÁCH 2: CHẠY TRỰC TIẾP TRÊN MÁY TÍNH (LOCALHOST)
----------------------------------------------------------------------------------------
Yêu cầu: Máy tính đã cài đặt NodeJS (phiên bản 18 trở lên).

BƯỚC 1: Cài đặt thư viện cho Giao diện (Frontend)
1. Mở cửa sổ Terminal (hoặc CMD / PowerShell) tại thư mục "manga":
   cd manga
2. Gõ lệnh cài đặt thư viện:
   npm install
3. Khởi chạy giao diện website:
   npm run dev
4. Trình duyệt sẽ mở website tại: http://localhost:5173

BƯỚC 2: (Tùy chọn) Chạy Backend API cục bộ (nếu muốn chạy offline)
1. Mở cửa sổ Terminal thứ 2 tại thư mục "backend":
   cd backend
2. Gõ lệnh cài đặt:
   npm install
3. Khởi chạy máy chủ:
   node server.js
   (Lưu ý: Mặc định Frontend đã kết nối sẵn với Backend Cloud Neon PostgreSQL nên bước này là tùy chọn).
